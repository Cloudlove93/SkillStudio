# EduSkill 扁平工作区与文档生成入口设计

## 调整目标

1. 去掉工作区最外层无意义的灰色包裹、12px 留白、圆角描边和整体阴影，让左栏、主区、右栏直接铺满窗口。
2. 区分“从描述文档生成 Skill”和“对话参考附件”，避免用户看不出原有文档生成功能。

## 界面设计

- 工作区采用全屏三栏布局，不再使用外层悬浮卡片效果；保留当前配色、侧栏结构和功能位置。
- “新建 Skill”增加独立的“从描述文档生成”方式，与自然对话、模板、导入 Skill、手动创建并列。
- 文档生成页面直接位于主内容区，只保留一层内容：标题说明、上传区域、文件列表、补充要求和生成按钮。
- 自然对话输入框左下角仅保留小型附件按钮，用于添加对话参考材料；附件上传后在输入框上方显示文件标签。
- “导入 Skill”继续只接收已有 Skill ZIP，不与描述文档生成混用。

## 功能规则

- 描述文档支持旧版文件格式：TXT、Markdown、DOCX、CSV、JSON、YAML、JavaScript、TypeScript、Python、HTML 和 CSS。
- 支持一次选择多份文档。
- 每份文档分别生成一个独立 Skill，不合并内容；页面展示每项任务的等待、生成、完成或失败状态。
- 单文档和批量任务生成完成后加入 Skill 仓库；单文档完成后进入对应 Skill 的“运行 Skill”页面，批量完成后进入仓库并展示结果。
- 自然对话中的参考附件继续随创建会话保存，不触发批量文档生成逻辑。

## 不调整范围

- 不改变现有主题颜色。
- 不修改 Skill 测试、Arena、优化、版本管理和右侧栏的业务逻辑。
- 不改变认证、Kong 和线上环境。

## 验收标准

- 页面不再出现最外层灰色圆角包裹。
- 用户能在左侧“新建 Skill”区域直接发现“从描述文档生成”。
- 文档生成、对话附件和 ZIP 导入三种行为在文案与交互上清楚区分。
- 多文档仍能分别生成多个 Skill。
- 常见桌面和窄屏尺寸下无横向溢出，左右栏开关不受影响。
