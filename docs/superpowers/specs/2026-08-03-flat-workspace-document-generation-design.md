# EduSkill 新建方式下拉菜单与材料入口微调设计

## 调整目标

1. 将当前常驻左侧栏的创建方式改为点击“新建 Skill”后出现的紧凑下拉菜单。
2. 恢复独立的“从描述文档生成”能力，并与对话参考附件、ZIP 导入明确区分。
3. 简化自然对话输入框中的“添加教学材料”，减少文字、底色和视觉层级。

## 界面设计

- 当前工作区的外围圆角、留白、配色、左右栏和主内容结构全部保持不变。
- 左侧常驻区只保留“新建 Skill”和“Skill 仓库”；点击“新建 Skill”显示下拉菜单，选择后自动关闭。
- 下拉菜单按以下顺序展示：自然对话创建、从描述文档生成、从模板创建、导入已有 Skill、空白创建。
- 每个菜单项显示图标、名称、简短说明和右箭头；文案使用用户确认的版本。
- 文档生成页面直接位于现有主内容区，只包含标题说明、上传区域、文件列表、补充要求和生成按钮。
- 自然对话输入框左下角改为一个小型附件图标按钮；通过标题或悬浮提示说明其作用。附件上传后仍在输入框上方显示文件标签。
- “导入已有 Skill”继续只接收标准 Skill ZIP，不与描述文档生成混用。

## 功能规则

- 描述文档支持旧版文件格式：TXT、Markdown、DOCX、CSV、JSON、YAML、JavaScript、TypeScript、Python、HTML 和 CSS。
- 支持一次选择多份文档。
- 每份文档分别生成一个独立 Skill，不合并内容；页面展示每项任务的等待、生成、完成或失败状态。
- 单文档和批量任务生成完成后加入 Skill 仓库；生成状态沿用现有任务反馈方式。
- 自然对话中的参考附件继续随创建会话保存，不触发批量文档生成逻辑。

## 不调整范围

- 不改变现有外围圆角、留白、主题颜色或阴影。
- 不修改 Skill 测试、Arena、优化、版本管理和右侧栏的业务逻辑。
- 不改变认证、Kong 和线上环境。

## 验收标准

- 左侧不再常驻展开五种创建方式。
- 点击“新建 Skill”可在下拉菜单中发现全部五种创建方式。
- 文档生成、对话附件和 ZIP 导入三种行为在文案与交互上清楚区分。
- 多文档仍能分别生成多个 Skill。
- “添加教学材料”不再显示两行文案和彩色块，只保留简洁附件入口。
- 常见桌面和窄屏尺寸下无横向溢出，外围圆角和左右栏开关不受影响。
