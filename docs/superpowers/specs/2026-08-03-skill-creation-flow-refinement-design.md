# EduSkill 创建流程微调设计

## 目标

只整理“新建 Skill”相关交互，减少页面层级和重复元素。工作区布局、左右侧栏、圆角、配色以及其他功能保持现状。

## 创建入口

“新建 Skill”下拉菜单保留四项：

| 名称 | 说明 | 行为 |
| --- | --- | --- |
| 对话共创 | 边聊边完善，也可从常用场景开始 | 进入自然对话创建页 |
| 文档生成 | 一份文档生成一个 Skill | 保留现有多文档独立生成功能 |
| 完整填写 | 按字段一次填写需求 | 进入轻量信息表 |
| 导入 Skill | 导入标准 Skill ZIP | 直接打开导入弹窗 |

删除独立的“从模板创建”入口。

## 对话共创

初始页面保留正常对话输入框。在输入框上方增加一行紧凑的“从常用场景开始”：

- 课堂活动设计
- 作业反馈
- 练习题生成

点击场景后，只把对应的起始描述填入输入框。用户可以继续修改，再自行发送；不自动提交，也不进入新的模板页面。

## 完整填写

不再把字段文字预填进对话框。创建区域改为单层、平整的轻量信息表，包含：

- Skill 名称
- 服务对象
- 使用场景
- 核心任务
- 输入内容
- 期望输出
- 规则与边界（可选）

服务对象与使用场景可以并排，输入内容与期望输出可以并排，减少页面高度。提交后沿用现有引导式创建流程，由后端继续检查和追问，不新增接口。

## 导入 Skill

点击菜单项后直接打开一个小型模态弹窗。弹窗只包含：

- ZIP 文件选择或拖拽区域
- 取消按钮
- 开始导入按钮
- 文件校验或导入错误提示

不切换到独立大页面，不显示对话输入框。导入服务和后端接口保持不变。

## 配色与样式约束

- 正式实现完全复用当前运行版本的 CSS 变量和组件颜色。
- 不新增独立色板，不写新的硬编码主题颜色。
- 不修改页面背景、侧栏、主区域、按钮和边框的现有配色。
- 保留当前外层圆角、间距基线以及浅色/深色主题行为。
- 可视化稿中的颜色仅用于说明结构，不作为实现依据。

## 影响范围

仅调整创建菜单和创建页面内部组件。Skill 仓库、运行、测试、Arena、优化、版本管理、右侧栏、后端和数据库均不修改。

## 验收

- 下拉菜单只有四项，名称和说明正确。
- 常用场景出现在“对话共创”初始页，点击后仅填充输入框。
- “完整填写”显示结构化信息表，不再向 textarea 写入字段模板。
- “导入 Skill”只打开弹窗，页面下方没有额外输入框。
- 文档生成、材料附件以及其他工作区功能仍可正常使用。
- 浅色和深色主题均与当前版本保持一致，没有新增配色冲突。
