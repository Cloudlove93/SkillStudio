# EduSkill 正式工作区设计

## 目标

将 EduSkill 调整为以 Skill 为核心的工作区，并正式部署到 `https://eduskill.innoagent.tech/login`。新界面保持现有视觉主题，不再以 Agent 为中心，不丢失已有创建、运行、测试、Arena、优化、版本和导入能力。

## 布局

### 左侧栏

- 顶部保留 EduSkill 品牌、`新建 Skill`、`Skill 仓库`和搜索。
- 点击 `新建 Skill` 后在左侧展开四种方式：自然对话、模板、导入、手动创建。
- 选中 Skill 后显示：运行、测试、Arena 对比、交互式优化、版本管理。
- 最近使用记录放在功能入口下方。
- 左下角只显示用户头像；账户、设置和退出放入头像菜单。

### 中间工作区

- 创建时只显示对话内容和底部输入框，不再居中展示大标题。
- 输入框提供醒目的 `添加教学材料`，注明支持 DOCX、Markdown、TXT，并支持拖放。
- Skill 创建完成后直接进入 `运行 Skill`，顶部显示轻量摘要：`Skill v1 已保存`。
- 运行、测试、Arena、优化和版本在同一工作区平滑切换，不叠加多层卡片。

### 右侧栏

- 默认关闭，保留窄工具栏。
- 创建进展、测试结果、优化建议等新信息出现时自动展开。
- 信息摘要使用顶部置顶提示，不使用抽屉。
- 右侧栏只展示当前任务所需信息，避免混放所有功能。

## 真实功能接入

- 创建：会话、消息、材料和草案保存到数据库。
- 运行：固定使用当前 Skill Version 执行，不依赖前端模拟回复。
- 测试：普通测试调用单版本执行；Arena 对比调用两个固定版本。
- 优化：复用交互式优化服务，确认后创建新版本。
- 版本：保留列表、详情、对比、回退、废弃和恢复。
- 仓库：展示当前用户的已创建 Skill 和未完成草稿。
- 导入、模板和手动创建均进入同一个 Skill 工作区。

## 创建后的使用流程

1. 用户通过自然对话、模板、导入或手动方式创建 Skill。
2. 后端校验并保存 Skill v1。
3. 前端直接进入 `运行 Skill`。
4. 用户可以立即输入真实任务。
5. 运行记录可继续进入测试、Arena 对比和优化。

## 错误处理

- 创建、运行、测试和优化失败时保留当前输入及数据库状态。
- 可重试操作必须提供明确重试按钮。
- 切换 Skill 不取消仍在后端执行的任务。
- 生产部署失败时不覆盖当前线上静态文件和服务。

## 验收标准

- `/login` 登录后进入 Skill 工作区。
- 创建入口位于左侧，中间无大标题占位。
- 上传入口对首次使用者清晰可见。
- 创建完成后直接运行真实 Skill。
- 原有运行、测试、Arena、优化、版本、导入功能均有明确入口并调用真实接口。
- 1440px、1024px、700px 窗口无横向溢出。
- 前后端构建通过，相关测试通过，线上健康检查和关键流程验证通过。
