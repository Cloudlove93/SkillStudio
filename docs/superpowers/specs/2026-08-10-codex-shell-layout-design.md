# Codex 式 Skill 工作台层级设计

## 目标

将 Skill 工作台的视觉与布局层级调整为：左侧导航独立成层，中间主内容与右侧上下文面板组成同一个工作区。只调整前端布局和开合行为，不改变现有业务功能、接口、数据和主题配色。

## 布局结构

```text
skill-workspace-root
├── skill-sidebar                 独立导航层
└── skill-workspace-surface       中间 + 右侧工作区
    ├── skill-main-column         主内容区
    └── skill-context             上下文区
```

外层使用 Grid：`sidebar-width + minmax(0, 1fr)`。工作区内部使用 Grid：`minmax(0, 1fr) + context-width`。所有可伸缩子项设置 `min-width: 0`，避免长标题、按钮或面板内容造成宽度抖动。

## 交互规则

- 左栏收缩只改变外层第一列，中心和右栏作为整体平移，不重新排列内容。
- 右栏展开只改变工作区内部第二列，不影响左栏宽度和状态。
- 右栏关闭时保留约 36px 的窄边作为重新打开入口；面板正文隐藏但不销毁，保留当前优化、版本或运行上下文。
- 右栏自动展开时沿用现有触发条件，不新增业务状态。
- 全屏只作用于工作区内容，不覆盖左栏；退出全屏后恢复原来的左栏和右栏状态。
- 视口较窄时，右栏在工作区内部转为覆盖层；桌面端保持稳定的双列工作区。

## 视觉规则

- 保留当前主题色、字体、按钮和图标，不重新设计配色。
- 左栏拥有独立背景和右侧分隔线。
- 中间与右栏共享工作区背景和外轮廓，避免看起来像两个互相独立的卡片。
- 只使用现有的圆角、阴影和边框变量，避免新增装饰层。
- 动画统一使用现有 200–240ms 缓动；禁止通过 `display`、内容重排或不稳定宽度计算制造跳动。

## 兼容性边界

- 不修改 Skill、会话、运行、测试、Arena、优化、版本管理的数据结构和路由。
- 不改变左栏中 Skill 与对话的层级关系、删除、重命名和右键操作。
- 不改变右栏中的版本、回答优化、运行信息和全屏功能，仅调整其所在布局层级。
- 不改变服务端接口和认证逻辑。

## 验收标准

1. 桌面端左栏始终独立，中心与右栏形成连续工作区。
2. 左栏收缩/展开时无内容抖动，右栏状态保持不变。
3. 右栏收缩/展开时不改变左栏宽度，中心内容不出现横向溢出。
4. 右栏关闭后仍可通过窄边打开，打开后保留上次所在面板和内容。
5. 全屏不遮挡左栏，退出后布局和滚动位置可恢复。
6. 小屏幕下主要交互仍可用，右栏不会把中心内容挤出视口。
7. 现有前端测试、Lint 和生产构建继续通过。
